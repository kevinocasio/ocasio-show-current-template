# Ocasio Show Current Template

Displays the active theme template filename and included template parts in the WordPress admin bar for administrators. Part of the lightweight **Ocasio Plugins** suite for WordPress.

---

## Features

* **Admin Bar Inspector:** Displays the active template filename (e.g., `single.php`, `page.php`) directly inside the top admin bar.
* **Template Part Hierarchy:** Lists all loaded theme partials and template parts upon hover.
* **Child Theme Aware:** Correctly differentiates between parent and child theme files.
* **Admin-Only Visibility:** Strictly visible to logged-in users with `manage_options` permissions.
* **Full Suite Integration:** Managed directly from the unified **Ocasio Plugins** dashboard at menu position 65.

---

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `ocasio-show-current-template.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings directly under the **Ocasio Plugins -> Dashboard** menu.
